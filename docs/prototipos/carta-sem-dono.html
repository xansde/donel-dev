O verso

De onde vem esta carta

Uma vez por noite, a faxina do Oráculo lê as tarefas sem usar modelo. Quando uma tarefa de risco baixo tem uma entrega cujo PR já entrou, ela a encerra como concluída. Uma tarefa de risco alto nunca se encerra sozinha.

O que continua sem dono há mais de um dia vira esta carta, uma só para todas, aqui e no celular.

Nas três primeiras noites

A faxina só anota o que faria, sem encerrar nem passar nada. Esta carta aparece mesmo assim, para você decidir à mão.

Como ler este protótipo. Na carta verdadeira, você clica uma vez para marcar e de novo para decidir, como nas outras cartas. «Ver uma a uma» abre os botões em cada linha. No celular, a carta fica sozinha na tela, sem a coluna das outras. Os nomes das tarefas aqui são de exemplo.
