# Modo Dev como montador de fluxo

## Pedido original

> "O modo dev no donel dev ficou muito datado. Ele é bonito, mas muito truncadinho. Ele não trás a facilidade de trabalhar que precisamos e acho que o Mindscape pode resolver isso. MAS, para isso funcionar como substituto, preciso conseguir configurar um fluxo de trabalho com você. Algo como um desenho de fluxograma das sessões, já levando em consideração um fanout, fanin, etc. A ideia é que o modo dev traga um molde de fluxo de sessões, onde cada sessão roda skills específicas e tenha um agente geral que veja o andamento de todas as sessões e consiga ser mais autônomo, além de conseguir sintetizar para me trazer apenas as dúvidas que realmente não são resolvíveis pelo agente. Se o modo dev virar um montador de fluxo e, no Mindscape, eu conseguir organizar um bloco dentro de um projeto para uma iniciativa (Uma trilha inteira a partir do discovery no modo dev) eu puder escolher o tipo dessa iniciativa (Desenvolvimento, Bugfix, Homologação, outras possíveis futuras), vai ser maravilhoso!"
