# design/ — material para o Claude Design

Tudo que vai para a ferramenta de design vive nesta pasta.

**Como usar:**

1. Envie primeiro o **[design-system.md](design-system.md)** — documento
   autocontido com todas as decisões visuais (cores, tipografia, componentes,
   estados do semáforo, smart zone, voz, identidade do Donel).
2. Depois gere as telas uma a uma com os briefs do
   **[design-handoff.md](design-handoff.md)** (14 briefs: Brief 0 é a versão
   condensada do design system — se o design-system.md já foi enviado no
   contexto, pode pular o Brief 0; Briefs 1–13 são as telas).
3. As telas geradas (exports, links, prints) devem ser salvas aqui em
   `referencia/` — elas são o gate da implementação (ver
   `specs/001-mvp/tasks.md`).

Fonte de requisitos por trás dos briefs: `specs/001-mvp/ui-spec.md` (vistas e
estados) e `specs/001-mvp/spec.md` (user stories e FRs).
