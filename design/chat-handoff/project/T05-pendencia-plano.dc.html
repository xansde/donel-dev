Trocar float por decimal.js no simulador

Hoje o cálculo usa float e arredonda com toFixed. O plano troca isso por Decimal sem mudar a regra de negócio: a diferença de centavos continua na última parcela.

  1. 1Instalar a biblioteca. npm install decimal.js, com a versão fixada no package.json.
  2. 2Criar o módulo de dinheiro. src/simulador/dinheiro.ts com somar, dividir e arredondar sobre Decimal.
  3. 3Trocar o cálculo. parcelas.ts passa a usar o módulo, e a regra da última parcela fica num lugar só.
  4. 4Atualizar os testes. Adaptar os 42 existentes e acrescentar casos de taxa zero e negativa.
  5. 5Conferir. Rodar npm test e npm run lint e revisar o relatório de repasse.
